# Prompt Engineering for Business ROI

> **Track:** Anthropic Enterprise Implementation (Track 1)

Design prompts that deliver measurable business outcomes through structured techniques and systematic evaluation.

---

## Modules

### Module 1: System Prompts & Role Definition

**Learning Objectives:**
- Write effective system prompts
- Define assistant persona and constraints
- Test prompt stability across inputs

### Module 2: Chain-of-Thought & Few-Shot Patterns

**Learning Objectives:**
- Apply chain-of-thought reasoning
- Construct few-shot examples
- Choose between zero-shot and few-shot approaches

### Module 3: Output Format Control

**Learning Objectives:**
- Force JSON and structured output
- Parse and validate model responses
- Handle edge cases in output parsing

### Module 4: Measuring Prompt Performance

**Learning Objectives:**
- Define prompt evaluation metrics
- Build prompt test suites
- Track performance over model updates
